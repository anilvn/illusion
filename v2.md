## 1. Problem Statement

### What is the task?
Build a machine learning application that automatically groups similar news articles into topic categories based on their content. The system should:
- Classify articles into predefined topics (Sports, Politics, Technology, Health, Entertainment)
- Find similar articles based on content similarity
- Enable category-based browsing and discovery

### Type of Learning
**Unsupervised Learning**
- No pre-labeled training data required
- Algorithm discovers patterns and groupings on its own
- Uses K-Means clustering to partition articles into K clusters
- Articles are grouped based on semantic similarity without explicit labels

### Why Unsupervised?
- News articles come without predefined category labels
- We want to discover natural groupings in the data
- Reduces manual labeling effort
- Adapts to new topics automatically

## 3. Methodology

### Algorithm Chosen: K-Means Clustering

#### Why K-Means?
| Criterion | K-Means | Alternatives |
|-----------|---------|--------------|
| **Scalability** | ✓ Excellent (O(n*k*i)) | Hierarchical: O(n²) |
| **Speed** | ✓ Fast convergence | DBSCAN: Slower |
| **Interpretability** | ✓ Clear cluster centers | Gaussian Mixture: Complex |
| **Implementation** | ✓ Simple, well-documented | Spectral: Complex |
| **Real-time Prediction** | ✓ Easy (distance to center) | Agglomerative: Difficult |

#### Why TF-IDF Vectorization?
- **Captures word importance:** Rare but meaningful words get higher scores
- **Reduces noise:** Common words (the, a, is) get low scores
- **Sparse representation:** Efficient storage for text data
- **Proven effective:** Industry standard for text clustering

### Steps Followed

#### Step 1: Data Loading & Exploration
```
Load articles from CSV/Database
├── Count total articles
├── Check for missing values
├── Analyze text length distribution
└── Identify unique sources/dates
```

#### Step 2: Text Preprocessing
```
For each article:
├── Convert to lowercase
├── Remove punctuation & special characters
├── Tokenize into words
├── Remove stopwords (the, a, is, etc.)
├── Optional: Lemmatization/Stemming
└── Store cleaned text
```

#### Step 3: TF-IDF Vectorization
```
Create vocabulary from all articles
├── Count unique words: ~5,000
├── Calculate TF (term frequency) per article
├── Calculate IDF (inverse document frequency) per word
├── Compute TF-IDF scores
└── Create sparse matrix: (1000 articles × 5000 words)
```

#### Step 4: Determine Optimal K (Number of Clusters)

**Method 1: Elbow Method**
```
For k = 1 to 10:
├── Run K-Means with k clusters
├── Calculate inertia (sum of squared distances)
└── Plot inertia vs k

Find "elbow point" where inertia decrease slows
Result: K = 5 clusters
```

**Method 2: Silhouette Score**
```
For k = 1 to 10:
├── Run K-Means with k clusters
├── Calculate silhouette score (-1 to 1)
└── Higher score = better clustering

Select k with highest silhouette score
Result: K = 5 clusters
```

#### Step 5: K-Means Clustering Algorithm

```
Initialize:
├── Randomly select K articles as initial cluster centers
└── Iteration = 0

Repeat until convergence:
├── Step 1: Assign each article to nearest cluster center
│   └── Use Euclidean distance in TF-IDF space
├── Step 2: Recalculate cluster centers
│   └── New center = mean of all articles in cluster
├── Step 3: Check convergence
│   └── If centers don't change, STOP
└── Iteration += 1

Output: Cluster assignment for each article
```

#### Step 6: Store Results

**Vector Database (Recommended)**
```
Pinecone / Weaviate / Milvus:
├── Store article vectors
├── Store cluster assignments
├── Enable similarity search
└── Fast retrieval (milliseconds)
```

#### Step 7: Evaluation & Visualization

**Metrics:**
- **Silhouette Score:** Measures cluster quality (-1 to 1)
- **Davies-Bouldin Index:** Lower is better
- **Calinski-Harabasz Index:** Higher is better
- **Inertia:** Sum of squared distances within clusters

**Visualizations:**
- Elbow curve (inertia vs K)
- Cluster distribution (bar chart)
- Word clouds per cluster
- 2D/3D scatter plot (t-SNE/PCA)

## 4. Code Snippet

### Complete Training Pipeline (Python)

```python
# PHASE 1: TRAINING
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score
import pandas as pd
import pickle

# 1. Load data
articles_df = pd.read_csv('news_articles.csv')
texts = articles_df['content'].tolist()

# 2. TF-IDF Vectorization
vectorizer = TfidfVectorizer(max_features=5000, stop_words='english')
tfidf_matrix = vectorizer.fit_transform(texts)

# 3. Determine optimal K using Elbow Method
inertias = []
for k in range(2, 11):
    kmeans = KMeans(n_clusters=k, random_state=42, n_init=10)
    kmeans.fit(tfidf_matrix)
    inertias.append(kmeans.inertia_)

# 4. K-Means Clustering (K=5)
kmeans = KMeans(n_clusters=5, random_state=42, n_init=10)
clusters = kmeans.fit_predict(tfidf_matrix)

# 5. Evaluate clustering
silhouette_avg = silhouette_score(tfidf_matrix, clusters)
print(f"Silhouette Score: {silhouette_avg:.3f}")

# 6. Save models
pickle.dump(vectorizer, open('vectorizer.pkl', 'wb'))
pickle.dump(kmeans, open('kmeans.pkl', 'wb'))
articles_df['cluster'] = clusters
articles_df.to_csv('clustered_articles.csv', index=False)
```

### Inference Pipeline (Real-time Queries)
